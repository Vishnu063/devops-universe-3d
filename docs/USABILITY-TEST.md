# Three-person usability check — not yet run

Status: **Pending real participants.** Automated tests do not replace observing people in a real browser. No participant results or performance measurements have been collected.

Ask three people who did not build the site to use it on their own device. Include at least one phone user and one DevOps beginner. Observe silently before helping; get their agreement before recording anything. Do not collect account credentials or personal network details.

Give each person these tasks:

1. Open the homepage and find the first action without instructions.
2. Scan, select a discovered topic and explain its beginner idea in their own words.
3. Find the deeper lesson without losing their place.
4. Find Security through Menu > Topics without scanning again.
5. Reset the camera and use tap/keyboard camera buttons without dragging.
6. Switch to the 2D map; find the same topic there.
7. Find Low quality and Reduce motion and explain what changed.
8. Open Build my network, run its example, remove an allow rule and explain the blocked result.

Record where they hesitate, misread a label, lose their place or need help. Note actual time to first topic, whether captions overlap, loading stalls, and camera/tap responsiveness. Do not count discovery as understanding or exercise completion.
